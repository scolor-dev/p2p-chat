# UI デザイン

## チャット画面（`chat-screen.svg` / `chat-screen.png`）

Figma の「Android Compact」（412 × 917）から書き出したもの。チャット画面（#26）の実装はこれに合わせる。

| 部分 | 内容 |
|---|---|
| トップバー | 青 `#2B60FF`、高さ 73。左に白い戻る矢印、中央に白い太字で相手の名前（図では「連絡先」は仮の文言） |
| 受信の吹き出し | 左寄せ。背景 `#A0B9E3`、文字は黒、角丸 10。改行できる |
| 送信の吹き出し | 右寄せ。背景 `#2B60FF`、文字は薄い青（`#A0B9E3` 系）、角丸 10 |
| 吹き出しの「しっぽ」 | **同じ人が続けて送った間は、いちばん下の吹き出しにだけ**付ける（受信は左下、送信は右下） |
| 下部の入力欄 | 青 `#2B60FF` の帯（ナビゲーションバーの領域まで続く）。白い角丸の入力欄（ヒント「メッセージを入力してください」は青文字）と、右に白い送信アイコン |
